# Student Performance Category Prediction

A small machine learning project that predicts a student's performance category—**Low**, **Medium**, or **High**—from study habits and previous academic information.

## Project objective

The target category is created from `Performance Index`:

- **Low:** Performance Index below 50
- **Medium:** Performance Index from 50 to below 75
- **High:** Performance Index of 75 or above

`Performance Index` is used only to create the target label. It is deliberately excluded from the model inputs to prevent target leakage.

## Input features

- Hours Studied
- Sleep Hours
- Previous Scores
- Sample Question Papers Practiced
- Extracurricular Activities (Yes/No)

The categorical activity feature is one-hot encoded by the model pipeline. Exact duplicate rows are removed before training; the project dataset contains 999 rows after this step.

## Model and evaluation

The project compares two depth-3 Decision Tree classifiers: a standard baseline and a class-weighted (`balanced`) version. Evaluation uses a stratified 80/20 train/test split and five-fold stratified cross-validation on the training portion. The held-out test set has 200 rows.

The balanced model is selected because it had better average cross-validation accuracy and macro F1, and it identified more High-category students on the held-out test set. Its held-out accuracy was slightly lower than the baseline, so the choice prioritizes more even class performance and improved High recall.

| Metric | Baseline | Balanced |
|---|---:|---:|
| 5-fold CV accuracy (mean ± SD) | 0.865 ± 0.022 | 0.875 ± 0.023 |
| 5-fold CV macro F1 (mean ± SD) | 0.848 ± 0.025 | 0.863 ± 0.026 |
| Held-out test accuracy | 0.890 | 0.885 |
| High-category precision | 0.96 | 0.78 |
| High-category recall | 0.66 | 0.84 |
| High-category F1 | 0.78 | 0.81 |

Balanced-model confusion matrix (rows = actual class, columns = predicted class; order = Low, Medium, High):

```text
[[76,  7,  0],
 [ 1, 69,  9],
 [ 0,  6, 32]]
```

The balanced model correctly identified 32 of 38 High-category students, compared with 25 of 38 for the baseline. It also predicted High for 9 Medium students. Consider this trade-off when using the predictions. The probability values printed by the tree are model estimates, not guaranteed or calibrated confidence levels.

## Project files

- `StudentPerformance.csv` — source dataset
- `student_performance_model.py` — cleans the data, compares models, reports evaluation metrics, and saves the final balanced pipeline
- `predict_student.py` — loads the saved pipeline and predicts a category for one new student
- `student_performance_model.joblib` — saved model, generated by the training script
- `Studentperformance.ipynb` — exploratory analysis and visualizations

## Run the project

Install the required packages in your Python environment if they are not already installed:

```bash
python -m pip install pandas scikit-learn joblib
```

Keep `StudentPerformance.csv` in the same folder as the scripts. Train and save the final model:

```bash
python student_performance_model.py
```

Then run an individual prediction:

```bash
python predict_student.py
```

Enter the requested student details when prompted. For example: 6 study hours, 7 sleep hours, previous score 75, 5 sample papers, and `Yes` for extracurricular activities.

## Notes

- The saved pipeline is fitted on all 999 deduplicated rows after the evaluation comparison, so it can be used for new-student predictions.
- Test-set metrics estimate performance on held-out rows from this dataset. They do not guarantee the same results for students from a different population or data source.
- This project predicts categories derived from Performance Index; it does not estimate an independently collected future score.
